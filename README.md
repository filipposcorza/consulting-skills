# Consulting Skills

A collection of AI agent skills for **change management, organizational assessment, workshop facilitation, and consulting methodology**.

Created by [Filippo Scorza](https://github.com/filipposcorza).

[![skills.sh](https://skills.sh/b/filipposcorza/consulting-skills)](https://skills.sh/filipposcorza/consulting-skills)

## Skills

| Skill | Description |
|-------|-------------|
| **assessment-engine** | Complete I5 assessment cycle: survey design, structured interviews, analysis, report, roadmap |
| **diagnostic-navigator** | Maps raw inputs (call notes, emails, symptoms) to structured problems (P1–P6) |
| **intervention-architect** | Designs intervention options from diagnosis, with evaluation criteria and success metrics |
| **mappatura-automazione-workflow** | Full workflow audit: real task mapping from calendar + interview, D×A classification, agent specification |
| **content-positioning-engine** | Plan and produce content (LinkedIn, blog, newsletter) aligned with F1–F6 frameworks |
| **workshop-facilitation-co-designer** | Design workshops and facilitation sessions: agenda, materials, key questions, expected outputs |
| **red-team-simulation-partner** | Simulates client conversations: skeptical CEO, CHRO selling internally, roadmap stress-test |
| **practice-based-consulting** | Extract client-facing advice from curated knowledge base, maps problems to proven frameworks |

## Install

```bash
npx skills add filipposcorza/consulting-skills
```
