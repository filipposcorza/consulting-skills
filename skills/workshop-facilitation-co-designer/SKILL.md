# Workshop & Facilitation Co-Designer

Carica questa skill quando il consulente chiede:
- "Progettami un workshop su X"
- "Ho bisogno di una scaletta per una sessione di Y ore"
- "Devo facilitare un incontro su [tema] — aiutami a strutturarlo"
- "Cosa abbiamo già fatto di simile?"
- "Disegnami l'agenda per la giornata con [cliente]"

```
## Workshop — [Titolo]
**Cliente:** [Nome]
**Durata:** [X ore / X giorni]
**Target:** [chi partecipa]
**Formato:** [presenza / remoto / ibrido]
**Obiettivo principale:** [cosa deve succedere alla fine]

### Obiettivi formativi specifici
- [obiettivo 1]
- [obiettivo 2]

### Agenda

| Orario | Durata | Attività | Metodo | Materiali | Output |
|--------|--------|----------|--------|-----------|--------|
| 09:00-09:15 | 15' | Check-in / Icebreaker | Domanda aperta | — | Energia gruppo |
| 09:15-09:45 | 30' | Framing del problema | Lecture + 1 slide | Slide | Contesto condiviso |
| ... | ... | ... | ... | ... | ... |

### Materiali necessari
- Slide, Miro board / canvas / template, post-it, pennarelli

- [domanda chiave per apertura]
- [domanda per momento di tensione]
- [domanda per chiusura / commitment]
```

## Procedure

### 1. Brief del workshop — dal bisogno alla scaletta

1. **Raccogli** dal consulente o dal CWM: cliente, contesto, obiettivo, target, durata, formato, output atteso
2. **Applica diagnostic-navigator** per capire il problema sottostante (Px)
3. **Cerca nel repertorio** workshop simili già fatti
4. **Struttura l'agenda:**
   - Apertura e framing (15-20% del tempo)
   - Parte teorica minima (20-30%)
   - Parte pratica/laboratoriale (40-50%)
   - Chiusura e commitment (10-15%)

### 2. Architettura oraria

| Durata workshop | Blocchi teorici | Attività pratiche | Pause |
|----------------|----------------|-------------------|-------|
| 3 ore | 1 blocco da 30' | 2 attività da 45' | 1 |
| 1 giornata (6-7h) | 2-3 blocchi da 20-30' | 3-4 attività | 2 |
| 2 giorni | 3-4 blocchi da 20-30' | 6-8 attività | 4-5 |

### 3. Metodi di facilitazione per tipo di output

| Output desiderato | Metodo consigliato | Tempo minimo |
|-------------------|-------------------|-------------|
| Mappatura problema | Problem framing canvas, customer journey map, empathy map | 60-90' |
| Generazione idee | SCAMPER, braindumping, worst idea, round robin | 30-45' |
| Prioritizzazione | Matrice impatto/sforzo, dot voting, decision matrix | 20-30' |
| Prototipazione | Paper prototype, role play, storyboard, Lego | 45-90' |
| Decisione di gruppo | Gradient of agreement, fist of five, consent decision | 15-30' |
| Allineamento stakeholder | Stakeholder map, power/interest grid | 45-60' |
| Piano d'azione | Timeline, RACI, next steps con owner e deadline | 20-30' |
| Retrospettiva | Start/stop/continue, 4L, sailboat | 30-45' |

### 4. AI-augmented facilitation

| Uso AI | Cosa fa l'AI | Cosa resta umano |
|--------|-------------|-----------------|
| Sintesi in tempo reale | Trascrive e riassume | Legge il clima, decide |
| Generazione varianti | Propone 3 versioni | Sceglie direzione |
| Analisi sentiment | Segnala energia, engagement | Interpreta, interviene |
| Preparazione materiali | Produce slide, canvas | Definisce contenuto |
| Documentazione post | Report, verbale, sintesi | Verifica, aggiunge insight |
